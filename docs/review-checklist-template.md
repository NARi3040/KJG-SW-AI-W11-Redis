# PR 체크리스트 템플릿

PR 본문에 그대로 붙여 넣고, 리뷰어가 자기 행만 채운다.

---

## 확인 요약

```markdown
## 변경 요약

- 변경 대상:
- 변경 이유:
- 확인한 것:
- 확인하지 못한 것:

## 리뷰 체크리스트

각 항목은 `파일:줄번호` 기준입니다. 결정은 `반영` / `철회` / `유지` / `보류` 중 하나입니다.

| 번 | 위치 | 내용 | 결정 | 담당 | 상태 |
| --- | --- | --- | --- | --- | --- |
| 1 | `파일:줄` |  |  |  | [ ] |
| 2 | `파일:줄` |  |  |  | [ ] |

## 미해결

- 없음

## 머지 조건

- [ ] 위 체크리스트가 모두 `반영` 또는 `철회`로 결론 났다
- [ ] 문서 간 상충(같은 규칙을 다르게 적은 곳)이 없다
- [ ] 실행해 확인한 것과 문서 검토만 한 것을 구분해 적었다
```

---

## 작성 규칙

1. **한 행에 한 지적**. 여러 위치를 한 행에 묶지 않는다.
2. **줄번호는 커밋 기준**. 줄이 밀릴 수 있으므로 해당 줄 텍스트도 함께 적는다.
   - 좋은 예: `planning.md:96` — `| Store | 입력 재검증 | …`
3. **결정 칸은 판단을 요구한다.** "확인 필요"처럼 애매한 값을 쓰지 않는다.
4. **상태는 체크박스로만 관리**한다. 본문에 "고쳤음"을 따로 적지 않는다.
5. 리뷰어가 늘어나면 **행을 지우지 않고 담당 칸만** 추가한다.
